# Paseo Plugin: File Inspector & Finder Reveal (`file-inspector-finder`)

An official-SDK [Paseo](https://github.com/getpaseo/paseo) plugin (`@getpaseo/plugin` `>=0.15.3`) that natively extends Paseo with **Schedule `Runs (N)` Execution History & 1-Click Session Drill-Down (`⌘⇧H` & `/schedule-runs`)**, **Project Workspace Quick Switcher (`⌘J` / `⌘⇧O` & Top-of-`⌘K` Direct Project Jump)**, **Zero-Popup Double-Click & `F2` Inline Workspace/Tab Rename**, **Sidebar Folder Drag & Drop Workspace Import (Auto-Dedupe)**, **Colored Workspace Labels (`⌘L` / `⌘⇧L`)**, **Reveal in Finder / Explorer**, **Open containing folder**, **Open in Preview / Code Editor**, **Image Pixel & Metadata Inspection**, and **Desktop Right-Click / `Option+Click` (`Alt+Click`)** across sidebars, file tabs, inline chat file links, workspace headers, `⌘K`, and slash commands.

- **Native-First & Conflict-Free**: Mounts an inline text editor directly inside left sidebar workspace rows (`sidebar-workspace-row-*`), top workspace header titles (`workspace-header-title`), and agent tabs (`workspace-tab-agent_*`) with zero modal popup; extends Paseo's official file tab context menu (`workspace-tab-context-*`) **in-place** right below `Copy file path`; suppresses Electron's fallback `Copy / Paste / Select All` menu when right-clicking inline chat file links; and leaves Paseo's native File Explorer menu untouched.
- **Native Single-Language i18n (`defineTranslations` / `useTranslation`)**: Automatically follows Paseo's active UI language (`en` or `zh` / `zh-CN`) in a single clean language without mixed bilingual labels or emoji clutter.
- **Update-Safe**: Runs in `~/.paseo/plugins/` and survives every `Paseo.app` upgrade.

Addresses community requests in [Discussion #4636](https://github.com/getpaseo/paseo/discussions/4636), [getpaseo/paseo#6482](https://github.com/getpaseo/paseo/issues/6482), [getpaseo/paseo#6691](https://github.com/getpaseo/paseo/issues/6691), and [Discussion #6123](https://github.com/getpaseo/paseo/discussions/6123).

## Quick Install (1 Command)

Make sure **Settings -> Plugins -> Enable plugins** is turned on in Paseo, then run:

```bash
paseo plugin install git:vecyang1/paseo-plugin-file-inspector-finder
```

Verify it is running:

```bash
paseo plugin ls
```

## Development & Verification

```bash
npm install
npm test
npm run typecheck
```

After a Paseo update, re-check Settings Search against the real app (needs the Paseo daemon on `:6767`, a `playwright-core` install and Playwright's Chromium; see `scripts/paseo-harness.mts`):

```bash
paseo plugin reload file-inspector-finder
# typo search, host and app routes, arrow keys, Enter -> row flashed, Esc (exit 0 = all checks passed)
node --experimental-strip-types --no-warnings --import ./test/register-ts.mjs scripts/settings-search-e2e.mts
# re-crawl every settings page; --check exits 1 when the committed seed is out of date, drop it to rewrite the seed
node --experimental-strip-types --no-warnings --import ./test/register-ts.mjs scripts/build-settings-search-seed.mts --check
```

Quote Reply against the real app (sends one real message to the given agent, so use a disposable session; `--no-send` stops before sending):

```bash
node --experimental-strip-types --no-warnings --import ./test/register-ts.mjs scripts/quote-reply-e2e.mts --agent <disposable-agent-id> [--server srv_x] [--no-send]
```
