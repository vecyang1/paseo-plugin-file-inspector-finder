# Paseo Powerpack (`paseo-powerpack`)

> **Formerly `File Inspector & Finder Reveal` (`file-inspector-finder`)** — Internal plugin ID remains `file-inspector-finder` so existing settings routes, `localStorage` preferences, and RPC contracts upgrade with zero breakage.

An official-SDK [Paseo](https://github.com/getpaseo/paseo) workbench powerpack plugin (`@getpaseo/plugin` `>=0.15.3`) that natively extends Paseo across **28+ surfaces**: **Multi-Document Preview & Side-by-Side Compare (`doc-inspector`)**, **Task Decisions Queue & In-Place Session Resume (`⌃⌘D` & `/decisions`)**, **Schedule `Runs (N)` Execution History & 1-Click Session Drill-Down (`⌘⇧H` & `/schedule-runs`)**, **Antigravity Subagent Tree (`⌘⇧B`)**, **Project Workspace Quick Switcher (`⌘J` / `⌘⇧O` & Top-of-`⌘K` Direct Project Jump)**, **Zero-Popup Double-Click & `F2` Inline Workspace/Tab Rename**, **Sidebar Folder Drag & Drop Workspace Import (Auto-Dedupe)**, **Colored Workspace Labels (`⌘L` / `⌘⇧L` + `1`–`9` keys)**, **Smart Dual-MIME Clipboard Copy (`⌘C`)**, **Quote Reply**, **Model Quick Switch (`⌘/`)**, **Sidebar Grouping Shortcuts (`⌃⌘P` / `⌃⌘S`)**, **Reveal in Finder / Explorer**, **Image Pixel & Metadata Inspection**, and **Desktop Right-Click / `Option+Click` / `⌘+Click`** across sidebars, file tabs, inline chat file links, workspace headers, `⌘K`, and slash commands.

- **Native-First & Conflict-Free**: Mounts an inline text editor directly inside left sidebar workspace rows (`sidebar-workspace-row-*`), top workspace header titles (`workspace-header-title`), and agent tabs (`workspace-tab-agent_*`) with zero modal popup; extends Paseo's official file tab context menu (`workspace-tab-context-*`) **in-place** right below `Copy file path`; suppresses Electron's fallback `Copy / Paste / Select All` menu when right-clicking inline chat file links; and leaves Paseo's native File Explorer menu untouched.
- **Native Single-Language i18n (`defineTranslations` / `useTranslation`)**: Automatically follows Paseo's active UI language (`en` or `zh` / `zh-CN`) in a single clean language without mixed bilingual labels or emoji clutter.
- **Update-Safe**: Runs in `~/.paseo/plugins/` and survives every `Paseo.app` upgrade.

Addresses community requests in [Discussion #4636](https://github.com/getpaseo/paseo/discussions/4636), [getpaseo/paseo#6482](https://github.com/getpaseo/paseo/issues/6482), [getpaseo/paseo#6691](https://github.com/getpaseo/paseo/issues/6691), and [Discussion #6123](https://github.com/getpaseo/paseo/discussions/6123). See [UPSTREAM.md](UPSTREAM.md) for the full live ledger of contributions and PRs sent to upstream `getpaseo/paseo`.

## Quick Install (1 Command)

Make sure **Settings -> Plugins -> Enable plugins** is turned on in Paseo, then run:

```bash
paseo plugin install git:vecyang1/paseo-powerpack
```

*(Legacy URL `git:vecyang1/paseo-plugin-file-inspector-finder` continues to work automatically via GitHub repository redirect.)*

Verify it is running:

```bash
paseo plugin ls
```
