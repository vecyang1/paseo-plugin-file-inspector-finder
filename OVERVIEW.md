File Inspector and Finder Reveal extends Paseo with fast Project Workspace Quick Switching (`⌘J` / `⌘⇧O` and pinned top-of-`⌘K` Project Jump actions without sub-thread clutter), Antigravity-style zero-popup double-click and `F2` inline workspace/tab rename, sidebar folder drag-and-drop workspace import (with automatic deduplication), colored thread labels, native Finder / Explorer reveal, system preview, editor launch, and image metadata inspection across sidebars, file tabs, inline chat file links, and workspace headers.

## Capabilities

- **Schedule `Runs (N)` Execution History & 1-Click Conversation Drill-Down (`⌘⇧H` & `/schedule-runs`)**: Injects an inline `Runs (N)` pill badge on every row in Paseo's `Schedules` screen (plus `View runs & conversation history (N)` in the `⋮` menu and an `All Runs (N) ⌘⇧H` toolbar button). Clicking opens an Antigravity-style **Schedule Detail & All Runs Drawer** showing schedule settings, prompt, and all historical runs with status, duration, output preview, inline conversation timeline preview, `▶ Run Now`, `Archive on finish` toggle, and **1-click `Open Conversation ↗`** (automatically unarchiving completed run workspaces via `restoreWorkspace(workspaceId)` and jumping to `/workspace/<workspaceId>`).
- **Project Workspace Quick Switcher (`⌘J` / `⌘⇧O`, Top-of-`⌘K` & `/jump`)**: Jump directly to any top-level project folder workspace without scrolling through dozens of sub-threads—supports post-date-prefix matching (`guan` -> `2026-11-07 Guan Tian Hao`), acronyms (`gth`), 0-thread empty projects, left-sidebar auto-expand & scroll (`Shift+Enter` for sidebar-only locate), and `Option+Enter` to spawn a fresh workspace thread.
- **Zero-popup double-click & `F2` inline rename**: Double-click any left sidebar workspace row, the top workspace header title, or any agent tab (or press `F2` / `⌘⇧E`) to edit the title directly in place with zero modal dialog (`Enter` or click outside saves; `Escape` cancels; full CJK IME safety).
- **Sidebar folder drag & drop workspace import**: Drag one or more folders from Finder onto Paseo's left sidebar (or Home `Add project` card) to switch to the workspace if it already exists or create it automatically if new (`Option+Drop` forces a fresh workspace thread).
- **Native file tab context menu extension**: Adds `Reveal in Finder`, `Open containing folder`, and `Open in Preview` directly inside Paseo's native file tab context menu right below `Copy file path`, with monochrome Lucide icons and zero overlapping menus.
- **Inline chat file link actions & shortcuts**: Supports right-click context actions (while suppressing Electron's duplicate fallback menu), `Option+Click` (`Alt+Click`) instant Finder reveal on any file link or tab, `⌘⇧R` to reveal the active file tab, `F2` / `⌘⇧E` for in-place inline rename, and `⌘⇧L` for quick colored workspace labels.
- **Image Inspector file panel (`image-inspector`)**: Enhances `.png`, `.jpg`, `.jpeg`, `.gif`, `.webp`, `.svg`, `.bmp`, `.ico`, `.avif`, `.heic`, `.tif`, and `.tiff` tabs with a top toolbar (`Reveal in Finder`, `Open containing folder`, `Open in Preview`, code editor launch, `Copy file path`, `Copy relative path`), zoom (`50%` to `300%`), Dark/Checker/Light canvas backgrounds, and a metadata bar showing pixel dimensions, file size, and modified time.
- **Workspace header popover and Explorer panel (`finder-panel`)**: Lists recently generated or modified images and files in the workspace, provides quick folder-to-workspace import, and supports one-click Reveal, Preview, and Copy Path actions.
- **Command Center (`⌘K`), slash commands (`/jump`, `/go`, `/open-folder`, `/reveal`, `/rename`, `/label`), and agent tools (`quick_jump_workspace`, `import_folder_workspace`, `reveal_in_finder`, `manage_thread_metadata`)**: Keyboard, chat composer, and agent-callable workspace and file ergonomics.
- **Native single-language localization**: Automatically follows Paseo's active UI language (`en` or `zh`) via `@getpaseo/plugin/client` translations.
- **Settings and live reconcilers (`Settings -> Plugins -> File Inspector & Finder`)**: Configure project workspace quick jump (`⌘J` / `⌘K`), inline double-click rename, sidebar drop behavior, default opener target, preferred editor, canvas background, and interactively preview project jump ranking scores, inspect/reset active workspace titles, check folder deduplication, and verify daemon path resolution.
